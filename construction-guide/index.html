Principio: Contract First
Ningún módulo se construye sin CONTRACT.xml aprobado. El contrato define entidades, campos, tipos, validaciones e invariantes antes de tocar HTML. Los gates verifican que el código respete el contrato. Si el gate falla, se bloquea la entrega.

Builder Guide — Agentes y Memoria

El orchestrator + sub-agentes que coordinan la construcción. La memoria append-only preserva decisiones entre sesiones. Los evaluators corren los gates.

★ Entrypoint Orchestrator Lee PLAN + memoria → resuelve orden de módulos → invoca agentes → corre gates → bloquea si falla. Agent Spec Agent Parsea el XML de cada módulo y emite parsed-spec estructurado para el contractor. Agent Memory Agent Append-only. Lee decisiones previas, escribe nuevas. Nunca borra, solo versiona. Agent State Agent Genera state.js con seed data desde el CONTRACT.xml. Gestiona localStorage. Agent Graph Agent Resuelve el DAG de dependencias entre módulos. Emite orden topológico de construcción. Agent Evaluator Agent Corre todos los gates: contract, visual, UX, state, responsive, perf. Bloquea si alguno falla.
